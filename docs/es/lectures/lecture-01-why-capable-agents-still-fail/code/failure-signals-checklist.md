# Checklist de señales de fallo

Usa esta checklist al revisar una ejecución con un harness débil.

- ¿El agent preguntó, o infirió mal, cómo arrancar la app?
- ¿Creó directorios o abstracciones que no encajan con el producto previsto?
- ¿Se detuvo tras crear una carcasa visible de UI sin un flujo completo?
- ¿Dejó notas o artefactos que ayuden a continuar una ejecución futura?
- ¿Una sesión fresca podría entender qué ocurrió en menos de cinco minutos?
