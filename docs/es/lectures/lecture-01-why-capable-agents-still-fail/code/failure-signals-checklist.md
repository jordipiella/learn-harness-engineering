# Fallo Signals Checklist

Usar this checklist when reviewing a weak harness ejecutar.

- Did the agent ask, or infer incorrectly, how to empezar the app?
- Did it crear directories or abstractions that do not match the intended
  product?
- Did it stop after making a visible UI shell without a completo flujo de trabajo?
- Did it leave notes or artifacts that help a future ejecutar continue?
- Could a fresh sesión entender what happened in under five minutes?
