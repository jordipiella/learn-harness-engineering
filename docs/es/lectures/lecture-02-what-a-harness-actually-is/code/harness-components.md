# Harness Components Ejemplo

For a agent de programación working in a local repositorio:

- Modelo:
  the LLM itself

- Harness:
  - system prompt
  - AGENTS.md
  - bash herramienta
  - archivo leer/escribir herramientas
  - git access
  - local filesystem
  - startup scripts
  - prueba comandos
  - stop hooks
  - lint checks
  - evaluador loop

If you cambio any of the above harness pieces, you cambio the effective agent.
