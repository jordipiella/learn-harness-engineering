# Glosario de traducción al español

Este glosario fija términos recurrentes para mantener coherencia en la localización española.

| Inglés | Español recomendado | Nota |
|--------|---------------------|------|
| harness | harness | Se conserva por ser el concepto central del curso. |
| Harness Engineering | Harness Engineering | Nombre del área; puede explicarse como ingeniería de entornos de ejecución para agents. |
| agent | agent | Se conserva para alinearlo con el vocabulario del curso. |
| AI coding agent | agent de programación con IA | Usar cuando se necesite aclarar el tipo de agent. |
| repository | repositorio | También puede usarse `repo` si aparece así en contexto técnico. |
| verification | verificación | Evitar traducir como validación cuando se refiere al proceso de comprobar trabajo del agent. |
| observability | observabilidad | Mantener como término técnico. |
| runtime | runtime | Mantener en inglés cuando se refiere al comportamiento durante ejecución. |
| scope | alcance | En contextos de control de trabajo: control de alcance. |
| session handoff | traspaso de sesión | Usar para notas o procedimientos que dejan contexto para la siguiente sesión. |
| feature list | lista de funcionalidades | Mantener `feature_list.json` como nombre de archivo. |
| Definition of Done | Definición de Terminado | Mantener mayúsculas cuando sea un concepto formal. |
| clean state | estado limpio | Usar para cierre de sesión y repositorio listo para continuar. |
| end-to-end | end-to-end | Mantener como término técnico ampliamente usado. |

## Reglas rápidas

- No traducir nombres de archivo, comandos, rutas, claves de configuración ni identificadores de código.
- Traducir el texto didáctico que rodea los artefactos técnicos.
- Preferir español neutro y directo.
- Si una traducción literal vuelve ambiguo un concepto del harness, conservar el término técnico y explicarlo.
