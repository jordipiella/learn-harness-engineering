# Proyecto 04. Usar Runtime Feedback to Correcto Agent Behavior

## What You Do

Añadir runtime observabilidad (startup logs, import/indexing logs, error states) and arquitectura constraints to prevent cross-layer violations. Plant a runtime bug for the agent to arreglar.

You ejecutar it twice: first without logs or constraints, second with proper herramientas and reglas.

## Herramientas

- Claude Código or Codex
- Git
- Node.js + Electron

## Harness Mechanism

Runtime feedback + alcance control + incremental indexing
