# Bienvenido a los proyectos

Esta es la parte práctica de Learn Harness Engineering. Leer las lecciones no basta: necesitas construir los entornos, ejecutar tareas reales y observar cómo Codex, Claude Code u otros agents se comportan bajo reglas distintas.

## Resumen del proyecto

El curso incluye 6 proyectos progresivos:

1. **Solo prompt frente a reglas primero**: compara cómo actúa un agent con un prompt suelto frente a un harness básico.
2. **Espacio de trabajo legible por agents**: estructura el repositorio para que sea comprensible para la IA y pueda dejar traspasos claros.
3. **Continuidad entre sesiones**: diseña archivos de estado e inicialización para reanudar trabajo sin redescubrirlo todo.
4. **Feedback en runtime y control de alcance**: introduce herramientas que permiten al agent probar su propio código y corregir errores.
5. **Autoverificación y separación de roles**: crea una revisión independiente para reducir alucinaciones y declaraciones tempranas de éxito.
6. **Harness completo (capstone)**: integra un entorno de trabajo observable y end-to-end.

## Cómo avanzar

Cada carpeta de proyecto suele incluir:

- `starter/`: tu punto de partida.
- `solution/`: una implementación de referencia.
- Instrucciones de tarea con contexto, objetivos y criterios de éxito.

Usa tu AI Coding Agent preferido, como Claude Code, Codex, Cursor o Trae, para completar las tareas dentro de `starter/`.
